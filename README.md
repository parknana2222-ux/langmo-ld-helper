## 🆕 RC8.15 Beta 1.5.4 주요 변경 사항

이번 버전은 기존 일일 원클릭의 안정성을 유지하면서 우편함·월드 사건 처리 및 주간 자동화 옵션을 보완한 베타 버전입니다.

### 일일 원클릭 안정화

- 조각작·비경 5종·영겁·부유성·시공·아레나 등의 완료 및 건너뛰기 판단 보완
- 화면 이동과 보상 수령 후 복귀 처리 개선
- 우편함에 수령할 우편이 없는 경우 정상 건너뛰기
- 기존 재화 소비 제한 및 불확실한 결과의 무조건 재시도 방지 유지

### 월드 사건 자동화

- 사건 목록을 스크롤하여 숨겨진 항목까지 탐색
- 보상 선택 우선순위: **크리스탈 → 장비 → 골드 → 기타**
- 소탕 또는 직접 AUTO 전투 방식 선택 지원
- 위 우선순위의 크리스탈은 **획득 보상**을 뜻하며 크리스탈을 자동 소비하는 기능이 아닙니다.

### 주간 자동화 [실험]

- 여단전 개인 점수 5,000점 목표 자동 소탕 옵션
- 초시공 시련 SSSS 자동화 옵션
- 신규 설치에서는 두 기능 모두 기본 OFF
- 여단전 6,300점 인식 및 목표 달성 상태에서 소탕 0회 정상 종료 확인

**주의:** 여단전 0→5,000점 연속 소탕 및 초시공 SSSS 전체 원클릭 완주는 아직 검증되지 않았습니다. 사용자가 직접 기능을 활성화해야 하며, 처음에는 일일 원클릭부터 확인하는 것을 권장합니다.

### 알려진 제한사항

일일 임무 이후 주간 기능으로 전환할 때 **도시→월드→도시의 불필요한 왕복 이동**이 일부 남아 있습니다. 현재 확인된 범위에서는 기능 수행을 방해하지 않아 이번 베타에서 수정하지 않았습니다.

한글 설치 경로에서 일부 주간 이미지 판독·진단 저장과 관련된 호환성 개선도 포함되어 있습니다.
