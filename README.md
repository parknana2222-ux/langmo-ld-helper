## 🆕 RC8.15 Beta 1.5.0 주요 변경 사항

### 1. 원클릭 시작 화면 대응 개선

기존 도시 메인뿐 아니라 월드맵에서도 원클릭을 시작할 수 있도록 개선했습니다.

- 월드맵에서 시작하면 도시로 자동 이동
- 도시 하단 메뉴가 접혀 있다면 필요한 메뉴를 펼친 뒤 실행
- 화면 상태를 확인한 후 다음 단계 진행

단, 인식하지 못하는 팝업이나 특수 화면에서 시작하면 안전을 위해 중단될 수 있습니다.

### 2. 조각작 및 비경 안정화

조각작 무료 횟수 판정과 비경 연속 진행을 개선했습니다.

- 영웅 조각작 대상 3~9명 지원
- 무료 횟수 0회 확인 시 유료 소탕 방지
- 운명의 문 체크 상태가 예상과 다른 경우 임의 변경 방지
- 비경 5종 화면 탐색·복귀 안정화
- 일부 비경 실패 시 안전하게 복귀할 수 있으면 후속 단계 진행
- 요일별 형귀·율정 설정 유지

완료 여부가 불확실한 숙제는 무조건 완료 처리하지 않고 별도로 기록합니다.

### 3. 친구 선물·우편함 자동화

친구 우정 포인트와 우편함 수령 기능을 원클릭에 통합했습니다.

**친구 선물**

- 일괄 전송 및 수령 처리
- 회색 버튼은 현재 처리 대상이 없는 상태로 판단
- 활성화된 버튼은 필요한 경우 한 번 처리
- 친구창 종료 후 도시 복귀 확인

**우편함**

- 받을 수 있는 우편 일괄 수령
- 보상 팝업 처리
- 일괄 수령 버튼이 없는 경우 건너뛰기
- 이미 수령한 우편이 목록에 남아 있는 경우도 고려

우편함에 과거 수령 완료 우편이 남아 있을 수 있으므로, 목록에 우편이 보인다는 이유만으로 미수령이라고 판단하지 않습니다.

### 4. 원클릭 오류 복구 및 상태 관리 개선

AuditVerified1에서 기존 자동화의 오류 대응을 추가로 보완했습니다.

- 일부 비경·아레나 화면 이동 실패 시 현재 화면 재확인
- 안전한 복귀 상태가 확인되면 가능한 후속 숙제 진행
- 실패한 숙제는 완료로 오인하지 않고 미확인으로 기록
- 이전 실행의 불확실 상태 관리 개선
- 소비 여부가 불확실한 경우 무리한 중복 클릭 방지

일일 상태 관리에는 한국시간 날짜 경계와 시작 화면 확인 조건이 적용되어 있습니다.

다만 실제 게임 서버의 초기화 상태를 직접 조회하는 방식은 아니며, 정확한 초기화 시각 및 예외 상황에 대해서는 추가 검증이 필요합니다.

**모든 오류를 자동 복구하는 것은 아닙니다.** 현재 화면이나 재화 소비 결과가 불확실한 경우에는 안전하게 중단할 수 있습니다.

### 5. GUI 간소화 및 코드 정리

기존의 여러 개별 숙제 실행·진단 기능을 정리하고 **원클릭 중심의 간단한 GUI**로 변경했습니다.

- 개별 숙제 실행 메뉴 제거
- 미사용 독립 진단·수동 복구 메뉴 정리
- 필수 실행 설정 중심으로 화면 간소화
- 실행 기록·화면 자료 메뉴 유지
- 상세 실행 로그를 TXT 파일로 열도록 개선
- 미사용 메서드 14개 제거 및 내부 코드 정리

실제 원클릭에 필요한 숙제 처리 함수와 이미지 인식 기능은 유지했습니다.

### 6. EXE 경량화

OpenCV에서 사용하지 않는 FFmpeg DLL을 제외하여 프로그램 배포 용량을 줄였습니다.

- 기존 ZIP 약 65MB → 경량판 약 52~53MB
- **다운로드 용량 약 19% 감소**
- 기존 PyInstaller One-folder 구조 유지
- Python 별도 설치 불필요
- 정식 EXE 패키징 및 DLL 검사 개선

경량화는 주로 다운로드·설치 용량 감소를 위한 것으로, 원클릭 실행 속도가 19% 빨라진다는 의미는 아닙니다.

### 7. 월드 사건 직접 전투(AUTO)

기존 월드 사건 소탕 방식 외에 직접 전투(AUTO) 선택 기능도 지원합니다.

다만 다양한 전투 상황에서 충분한 실전 검증이 완료된 기능은 아닙니다.

**현재는 기본 설정인 소탕 방식을 권장합니다.**

단, 해당 실행에서는 이미 대부분의 숙제가 완료되어 있었으므로 신규 소탕·전투 전체 경로를 다시 검증한 것은 아닙니다.

다만 오프라인 검사와 실제 LDPlayer 게임 실행은 서로 다른 검증입니다.
