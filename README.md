**랑그릿사 모바일 한국 서버용 원클릭 일일 숙제 자동화 도우미**

Windows + LDPlayer 9 환경에서 반복적인 일일 숙제를 간편하게 처리하기 위해 만든 **비공식 개인 제작 프로그램**입니다.

**현재 버전: v1.10.44-RC8.15 · Beta 1.6.12 (2026-10-27)**

> 🎉 **Python 설치 없이 EXE로 실행할 수 있습니다!**
>
> ZIP 전체 압축 해제 후 `랑모도우미.exe`를 실행하면 됩니다.
>
> 이번 업데이트에서는 **일일 원클릭 숙제 선택 실행, ADB 연결 개선, 설정 화면 정리, 우정 소환 연출 단축 및 자동화 안정성 개선**을 진행했습니다.

### 추가 설정 및 편의 기능

- **원클릭 체크리스트:** 원하는 일일 숙제만 선택하여 실행

- **ADB 연결 관리:** LDPlayer 기기 검색·선택 및 연결 설정 저장
- **조각작 인원 3~9명 선택**
- **시공 스테이지 직접 등록:** 챕터 배너·정예 노드·상세 제목을 이용한 사용자 등록
- **시공 이동 경로 검사:** 실제 소탕 없이 등록 스테이지 진입 경로 확인
- 요일별 형귀·규율의 여정 대상 선택
- 행동력 부족 시 제한적인 자동 버거 사용
- 소탕 티켓 사용 동의 및 소비 횟수 제한
- 도시 메인·월드맵에서 원클릭 시작 지원
- 이미 완료했거나 횟수가 소진된 숙제 건너뛰기
- 일부 화면 이동 실패 시 제한적인 자동 복구
- 원클릭 진행 상황 및 최종 결과 요약
- 실행 로그, 원본 PNG 캡처 및 오류 보고 ZIP 저장
- EXE 폴더의 `UserData`에 사용자 설정·로그·이미지 저장

**참고:** 일일 임무 중 **「비경에서 스태미나 300 소모」는 필수 완료 대상에서 제외**합니다.

## 🆕 RC8.15 Beta 1.6.12 주요 변경 사항

이번 버전은 기존 일일 원클릭 안정화를 이어가면서 사용자 편의성과 ADB 연결 호환성을 개선한 베타 버전입니다.

### 1. 일일 원클릭 체크리스트 추가

- 원하는 일일 숙제만 선택하여 실행 가능
- 선택하지 않은 작업은 건너뛰기
- 일부 숙제만 완료하거나 다시 실행하려는 상황에서 활용 가능
- 부분 선택 실행 기본 동작 실사용 확인

### 2. 설정 화면 및 ADB 연결 개선

- 설정 화면을 4개 탭으로 정리
- LDPlayer ADB 기기 자동 검색 및 선택 기능 개선
- 연결 대상 저장 및 재연결 처리 보완
- 기존 단일 인스턴스 외의 설치·연결 환경 대응 강화

### 3. 우정 소환 연출 단축 개선

- 우정 소환 시계 회전 애니메이션 단축 처리 추가
- 화면 상태를 확인한 경우에만 추가 클릭
- 불확실한 화면에서는 기존처럼 안전하게 대기
- 중복 클릭을 제한하여 잘못된 입력 방지

**참고:** 해당 단축 기능의 실제 게임 환경 검증은 진행 중입니다.

### 4. 일일 자동화 안정성 개선

- 조각작·비경 5종·시공·아레나 등의 예외 상황 대응 보완
- 완료·건너뛰기 판정 개선
- 화면 이동 및 보상 수령 후 복귀 처리 보강
- 버거·소탕권 소비 상한 및 안전 중단 로직 유지
- 불확실한 결과에서 무조건 재클릭하지 않도록 제한

### 5. 월드 사건 자동화

- 사건 목록 스크롤 및 숨겨진 항목 탐색
- 보상 선택 우선순위: **크리스탈 → 장비 → 골드 → 기타**
- 소탕 또는 직접 AUTO 전투 방식 지원

**참고:** 위 크리스탈은 획득 보상을 의미하며 자동 소비하는 기능이 아닙니다.

### 6. 주간 자동화 [실험]

- 여단전 개인 점수 5,000점 목표 자동 소탕 옵션
- 초시공 시련 SSSS 자동화 옵션
- 초시공 위탁 완료 상태에서 마지막 전투로 이어지는 재개 경로 보강
- 신규 설치에서는 주간 기능 기본 OFF
- 중복 입력과 불확실한 재화 소비를 제한하는 안전장치 적용

**주의:** 여단전 0→5,000점 전체 연속 소탕 및 초시공 SSSS의 마지막 전투까지 무개입 완주는 아직 충분히 검증되지 않았습니다.

처음 사용하는 경우 일일 원클릭부터 확인한 후 주간 기능을 별도로 활성화하는 것을 권장합니다.

## 🔧 검증 및 알려진 제한사항

- 오프라인 빠른 회귀검사 **507개 통과, 2개 건너뜀**
- 일부 과거 회귀검사에 필요한 외부 스크린샷 자료가 없어 전체 검증은 미완료
- 일일 원클릭은 실사용에서 정상 완주 사례가 확인되었으나, 모든 실행 환경에서의 성공을 보장하지 않음
- 주간 기능 및 우정 소환 신규 연출 단축 기능은 추가 실사용 검증 필요
- 일일 임무 이후 주간 기능 전환 과정에서 불필요한 화면 왕복 이동이 일부 남아 있을 수 있음
- 예상하지 못한 화면이나 팝업에서는 안전을 위해 자동화를 중단할 수 있음

본 프로그램은 **비공식 개인 제작 자동화 도구**입니다. 게임 업데이트나 실행 환경에 따라 오류가 발생할 수 있으며, 게임 운영정책에 따른 계정 제한 등의 위험이 있습니다.

문제가 발생하면 실행 로그 및 오류 보고 ZIP과 함께 발생한 숙제, 당시 화면 상태, 재현 방법을 알려주세요. 오류 자료를 공유하기 전 개인정보가 포함되어 있는지 확인해 주세요.
