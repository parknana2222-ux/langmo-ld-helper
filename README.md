## 🖥️ 사용 환경

| 항목 | 필요 조건 |
| :-- | :-- |
| 운영체제 | Windows 10 / 11, 64비트 |
| 에뮬레이터 | LDPlayer 9 |
| 게임 화면 | **1280 × 720** 해상도 |
| 게임 | 랑그릿사 모바일 한국 서버 |
| Python | Python 3.12 또는 3.13, 64비트 |
| ADB 연결 | `emulator-5554` 환경 기준 |

### 필수 프로그램 다운로드

- 🐍 [Python 3.13.16 공식 다운로드](https://www.python.org/downloads/release/python-31316/) — Windows installer (64-bit) 선택
- 📱 [LDPlayer 공식 버전 선택 페이지](https://kr.ldplayer.net/versions) — **LDPlayer 9** 선택

Python 설치 시 Python Launcher와 Tcl/Tk 구성 요소가 포함되어 있어야 합니다.

> 💡 Python이나 LDPlayer가 이미 설치되어 있어도 버전, 64비트 여부, 해상도를 확인해 주세요. 현재 배포판은 다른 에뮬레이터와 해상도를 공식 지원하지 않습니다.

## 🚀 처음 실행하는 방법

1. 실행용 ZIP을 다운로드하고 **압축을 모두 해제**합니다.
2. 압축 해제 폴더의 **`00_사용안내.html`**을 열어 자세한 설명을 확인합니다.
3. Python 3.12/3.13(64비트) 및 LDPlayer 9를 설치합니다.
4. LDPlayer 9에서 게임 해상도를 **1280×720**으로 맞추고 랑그릿사 한국 서버를 실행합니다.
5. 프로그램 폴더의 **`setup.bat`을 최초 1회 실행**합니다. 패키지 설치를 위해 인터넷 연결이 필요합니다.
6. 설치가 완료되면 **`run.bat`**을 실행합니다.
7. 프로그램에서 **요일별 설정, 자동 버거, 소탕 티켓 사용 동의**를 확인합니다.
8. **전체 원클릭**을 눌러 숙제를 진행합니다.
9. 종료 후 완료·미확인 결과를 확인하고 실제 게임에서도 완료 여부를 살펴봐 주세요.

> 📌 이 패키지는 단독 EXE가 아닙니다. Python 설치가 필요하며 `setup.bat`, `run.bat`으로 실행합니다.

> 📌 처음 사용하는 경우에는 실행 화면을 지켜보면서 정상적인 버튼 인식과 재화 사용 설정을 확인하는 것을 권장합니다.

## ⚠️ 베타 테스트 안내 및 주의사항

- **시험판입니다.** 제작 환경에서 정상 작동한 구간이 있지만, 일일 초기화 직후 전체 숙제의 다양한 PC 환경 무개입 완주는 아직 충분히 검증되지 않았습니다.
- 자동 버거·소탕 티켓 사용 여부는 실행 전 설정을 직접 확인해 주세요. 화면 지연이나 인식 오류로 원하지 않는 재화 사용 또는 숙제 누락이 발생할 가능성이 있습니다.
- 화면 구성 변경, 게임 업데이트, 에뮬레이터 환경 차이에 따라 오작동할 수 있습니다.
- 게임 운영정책에 따라 자동화 도구 사용에 **계정 이용 제한 등의 위험**이 있을 수 있습니다.
- 이 프로그램은 게임사에서 제작하거나 승인한 공식 프로그램이 아닙니다.

## 🛠️ 오류가 발생했나요?

먼저 다음 사항을 확인해 주세요.

1. LDPlayer 9를 실행하고 게임 화면이 **1280×720**인지 확인
2. `setup.bat` 실행 중 설치 오류가 없었는지 확인
3. 게임이 정상적으로 실행되고 ADB 장치가 연결되어 있는지 확인
4. 같은 숙제를 무작정 반복하지 말고 **게임 내 완료 여부 및 재화 사용 상태**를 먼저 확인

### 오류 제보 시 필요한 정보

- 문제가 발생한 숙제 단계
- 당시 게임 화면 스크린샷
- `logs/session.txt`
- `logs/oneclick_latest.json`
- Windows / Python / LDPlayer 버전

### [💬 오류 및 개선 의견 남기기 (GitHub Issues)](https://github.com/parknana2222-ux/langmo-ld-helper/issues)

> 🔒 로그·스크린샷에는 게임 닉네임, PC 사용자 경로 등의 개인정보가 포함될 수 있습니다. 공개 게시글이나 Issues에 첨부하기 전 확인하고 가려 주세요.
