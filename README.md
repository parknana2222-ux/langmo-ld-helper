# 🎮 랑모 LD 도우미

**랑그릿사 모바일 한국 서버용 원클릭 일일 숙제 자동화 도우미**

Windows + LDPlayer 9 환경에서 반복적인 일일 숙제를 간편하게 처리하기 위해 만든 **비공식 개인 제작 프로그램**입니다.

**현재 버전: v1.10.44-RC8.15 · Beta 1.6.27 (2026-10-28)**

> 🎉 **Python 설치 없이 EXE로 실행할 수 있습니다!**
>
> ZIP 전체 압축 해제 후 `랑모도우미.exe`를 실행하면 됩니다.
>
> 이번 업데이트에서는 **비경 5종·영겁의 신전 완료 판정 최적화, 조각작·자동 버거 처리 개선, 사용자 설정 보존, 원클릭 편의성 및 안정성 개선**을 진행했습니다.

- **ADB 연결 관리:** LDPlayer 기기 검색·선택 및 연결 설정 저장

- **시공 스테이지 직접 등록:** 챕터 배너·정예 노드·상세 제목을 이용한 사용자 등록
- **시공 이동 경로 검사:** 실제 소탕 없이 등록 스테이지 진입 경로 확인

- 행동력 부족 시 제한적인 자동 버거 사용
- 소탕 티켓 사용 동의 및 소비 횟수 제한
- 도시 메인·월드맵에서 원클릭 시작 지원
- 완료했거나 횟수가 소진된 숙제 자동 건너뛰기
- 일부 화면 이동 실패 시 제한적인 자동 복구
- 최근 원클릭 실행 통계 및 작업별 소요 시간 확인

- **사용자 설정·등록 시공 프로필을 프로그램 폴더 외부에 보존**

**참고:** 일일 임무 중 **「비경에서 스태미나 300 소모」는 필수 완료 대상에서 제외**합니다.

## 🆕 RC8.15 Beta 1.6.27 주요 변경 사항

이번 버전은 기존 일일 원클릭 자동화를 유지하면서 **반복 실행 효율, 인식 정확성, 사용자 편의성 및 유지보수성**을 개선한 베타 버전입니다.

### 1. 비경 5종·영겁의 신전 속도 최적화

- 비경 목록에서 남은 일일 보상 횟수를 먼저 확인
- **보상 0회를 확실하게 확인하면 해당 던전 입장 생략**
- 형귀·여신·특훈실·유대의 땅·규율의 여정 5종 적용
- 영겁의 신전도 목록에서 도전 횟수 `0/1` 확인 시 입장 생략
- 보상 횟수가 남아 있거나 인식이 불확실하면 기존 던전 내부 확인 방식 유지
- 별도 완료 기록이나 추가 설정 없이 기존 원클릭에 자동 적용

**실사용 비교:** 이미 보상이 소진된 상태에서 비경 5종+영겁 확인 시간이 약 41.5초(Beta 1.6.25)에서 약 13.8초(Beta 1.6.27)로 감소한 사례를 확인했습니다.

실행 환경과 남은 보상 횟수에 따라 실제 소요 시간은 달라질 수 있습니다.

### 2. 조각작 및 일일 비경 안정성 개선

- 조각작 무료 도전 횟수 `3 + 추가 횟수` 판독 오류 수정
- 무료 소탕 횟수 감소 및 완료 판정 개선
- 비경 일일 보상 HUD 보조 인식 기능 추가
- 조건부 비경 연속 소탕 지원
- 이미 소진된 보상 횟수에 대한 중복 소탕 방지
- 인식 결과가 불확실한 경우 기존 안전 중단 및 재확인 규칙 유지

### 3. 자동 버거 사용 및 복귀 처리 개선

- 기존 공통 자동 버거 사용 기능 재사용
- 행동력 부족 팝업과 일반 버거 사용 확인 절차 유지
- 버거 사용 후 각 숙제의 원래 화면 복귀 판정 개선
- 행동력 숫자 변화만을 필수 성공 조건으로 요구하지 않도록 보완
- 조각작 영웅 목록 복귀 및 동일 영웅 재확인 경로 추가
- 버거·소탕권 사용 상한과 프리미엄 재화 소비 방지 유지
- 사용 결과가 불확실할 때 무조건 재클릭하지 않도록 제한

**참고:** 자동 버거 사용 후 복귀 개선은 오프라인 검증을 진행했으며, 모든 숙제에서의 실전 성공을 보장하지 않습니다.

### 4. 원클릭 체크리스트 및 설정 화면 개선

- 메인 화면에서 오늘 실행할 숙제를 펼쳐 선택 가능
- 설정 화면을 **3개 탭**으로 정리
- 중복된 체크리스트 설정 화면 및 불필요한 안내 제거
- 기존 숙제별 선택 실행 기능 유지
- 일부 숙제만 완료하거나 나중에 원클릭을 다시 실행하는 상황에 대응
- 이미 완료한 숙제는 게임 화면의 완료 상태에 따라 건너뛰기

### 5. 사용자 데이터 보존 기능

- 사용자 설정과 등록한 시공 프로필의 저장 위치를 프로그램 폴더 외부로 분리
- 새 버전으로 교체해도 기존 설정과 등록 데이터를 재사용할 수 있도록 개선
- 기존 데이터가 존재하는 경우 복사 방식의 이관 지원
- 이관 시 기존 원본 데이터 보존
- 실행 로그·실패 화면·주간 진행 기록은 각 버전의 프로그램 폴더에서 관리

**주의:** 새 버전으로 교체하면 주간 완료 기록이 초기화될 수 있습니다. 또한 기존 설정을 백업하지 않은 상태에서 구버전 데이터 폴더를 삭제하면 복구가 어려울 수 있습니다.

### 6. 우정 소환 및 월드 사건 자동화

**우정 소환**
- 소환 시계 회전 연출 단축 기능 지원
- 화면 상태 확인 후 제한적인 추가 입력
- 완료된 일일 임무를 확인한 경우 불필요한 재소환 생략

**월드 사건**
- 사건 목록 스크롤 및 숨겨진 항목 탐색
- 보상 선택 우선순위: **크리스탈 → 장비 → 골드 → 기타**
- 소탕 또는 직접 AUTO 전투 방식 지원
- 임무 완료 상태에 따라 재실행 생략

**참고:** 크리스탈은 획득 보상을 의미하며, 자동 소비하는 기능이 아닙니다.

### 7. 주간 자동화 [실험]

- 여단전 개인 점수 5,000점 목표 자동 소탕 옵션
- 초시공 시련 SSSS 자동화 옵션
- 초시공 위탁 완료 이후 마지막 전투로 이어지는 재개 경로 보강
- 부분 위탁 진행 상태 확인 및 오류 증거 수집 기능 보완
- 이미 완료된 초시공 시련 확인 시 불필요한 전투·위탁 생략
- 신규 설치에서는 주간 자동화 기본 OFF
- 중복 입력과 불확실한 재화 소비를 제한하는 안전장치 유지

**주의:** 여단전 0→5,000점 전체 연속 소탕 및 초시공 SSSS의 부분 위탁부터 마지막 전투까지 완전 무개입 진행은 아직 충분히 검증되지 않았습니다. 일부 중간 위탁 자동 재개 기능은 미완성입니다.

처음 사용하는 경우 일일 원클릭부터 확인한 후 주간 기능을 별도로 활성화하는 것을 권장합니다.

### 8. 실행 기록 및 개발 품질 개선

- 최근 원클릭 실행 결과 및 작업별 소요 시간 통계 추가
- 화면 캡처·판독·이동 시간 계측
- 오류 발생 시 로그와 화면 자료 수집 기능 개선
- 실제 실패 PNG와 기대 판독 결과를 회귀검사에 등록하는 개발 도구 추가
- 기존 자동화 코드와 인식 에셋을 유지하면서 불필요한 개발 산출물 정리

## 🔧 검증 및 알려진 제한사항

- Beta 1.6.27 관련 집중 회귀검사 **84개 통과**
- 기존 빠른 회귀검사는 Beta 1.6.26에서 525개 통과·2개 건너뜀
- Beta 1.6.27의 전체 빠른 회귀검사는 실행 시간 제한으로 최종 완료하지 못함
- 일부 과거 회귀검사에 필요한 외부 스크린샷 자료가 없어 전체 검증 미완료
- 실제 LDPlayer에서 비경 5종·영겁의 신전 목록 완료 판정 및 입장 생략 확인
- 완료된 일일 숙제를 다시 확인하는 원클릭 실행에서 정상 종료 사례 확인
- 보상 횟수가 남아 있는 경우와 자동 버거 복귀 등 일부 경로는 추가 실사용 검증 필요
- 주간 자동화 기능은 실험 단계이며 전체 무개입 완주를 보장하지 않음
- 예상하지 못한 화면이나 팝업에서는 안전을 위해 자동화를 중단할 수 있음

본 프로그램은 **비공식 개인 제작 자동화 도구**입니다. 게임 업데이트나 실행 환경에 따라 오류가 발생할 수 있으며, 게임 운영정책에 따른 계정 제한 등의 위험이 있습니다.

문제가 발생하면 실행 로그 및 오류 보고 ZIP과 함께 발생한 숙제, 당시 화면 상태, 재현 방법을 알려주세요. 오류 자료를 공유하기 전 개인정보가 포함되어 있는지 확인해 주세요.
