## 🚀 처음 실행하는 방법

1. 위 다운로드 페이지에서 **User_EXE.zip**을 다운로드합니다.
2. ZIP을 **전체 압축 해제**합니다. ZIP 안에서 바로 실행하지 마세요.
3. 압축을 푼 폴더의 **`00_사용안내.html`**을 열어 설명을 확인합니다.
4. LDPlayer 9에서 게임 화면을 **1280×720**으로 설정하고 랑그릿사 한국 서버를 실행합니다.
5. 게임의 **도시 메인 화면**으로 이동하고 열린 팝업을 닫습니다.
6. `랑모도우미` 폴더 안의 **`랑모도우미.exe`**를 실행합니다.
7. 프로그램에서 ADB 연결, 요일별 설정, 시공 대상, 자동 버거, 소탕 티켓 사용 동의를 확인합니다.
8. **전체 원클릭**을 누르고 실행 동의 내용을 확인한 뒤 시작합니다.
9. 종료 후 완료·미확인 결과를 확인하고 실제 게임에서도 숙제 완료 여부를 살펴봐 주세요.

> 📌 `랑모도우미.exe` 옆의 `_internal` 폴더는 실행에 필요한 파일입니다. **EXE만 따로 옮기거나 `_internal`을 삭제하면 안 됩니다.**
>
> 📌 처음 사용할 때는 실행 과정을 지켜보면서 화면 인식과 재화 사용 설정을 확인하는 것을 권장합니다.

## 📂 설정·로그 저장 및 업데이트

EXE판은 실행 시 프로그램 폴더 안에 **`UserData`**를 자동 생성합니다.

주요 저장 위치는 다음과 같습니다.

| 경로 | 내용 |
| :-- | :-- |
| `랑모도우미/UserData/logs` | 실행 로그 및 진단 이미지 |
| `랑모도우미/UserData/screenshots` | 수동 저장 스크린샷 |
| `랑모도우미/UserData/rift_profiles` | 사용자 등록 시공 프로필 |
| `랑모도우미/UserData/assets` | 실행용 에셋 및 사용자 등록 이미지 |
| `랑모도우미/UserData/*.json` | 요일별 설정, 자동 버거 등 |

### 업데이트할 때

**기존 `UserData` 폴더를 백업한 후, 새 버전의 `랑모도우미` 폴더에 복사해 주세요.**

특히 직접 등록한 시공 스테이지는 다시 캡처하는 번거로움을 피하려면 `UserData`를 보존하는 것이 좋습니다.

기존 Python 실행판이나 이전 PyInstaller 시험판의 설정은 새 포터블 EXE로 자동 이전되지 않습니다. 필요하면 기존 등록 프로필을 별도로 옮기거나 다시 등록해 주세요.

자동 진단 로그와 이미지에는 보관 한도가 적용됩니다. 다만 사용자가 직접 저장한 스크린샷은 자동 삭제되지 않을 수 있습니다.

> ⚠️ 프로그램 폴더를 통째로 삭제하면 `UserData`도 함께 삭제됩니다. 업데이트하거나 제거하기 전에 필요한 시공 프로필을 백업해 주세요.

## ⚠️ 베타 테스트 안내 및 주의사항

- **베타 버전입니다.** 개발 환경에서 EXE 원클릭 실행 및 기본 시공 26-3 탐색을 확인했지만, 모든 사용자 환경에서의 무개입 완주를 보장하지 않습니다.
- 기본 26-3의 챕터 탐색·정예 스테이지 진입 및 금일 도전 횟수 소진 판정은 실전 확인했습니다. 이번 버전에서 초기화 직후 실제 소탕 3회를 새롭게 검증한 것은 아닙니다.
- 자동 버거·소탕 티켓 사용 여부는 실행 전 직접 확인해 주세요. 화면 인식 오류로 숙제 누락이나 의도하지 않은 재화 소비가 발생할 가능성을 배제할 수 없습니다.
- 게임 업데이트, 화면 구성 변경, 에뮬레이터 환경 차이에 따라 오작동할 수 있습니다.
- 게임 운영정책에 따라 자동화 도구 사용으로 **계정 이용 제한 등의 위험**이 있을 수 있습니다.
- 이 프로그램은 게임사 또는 LDPlayer 개발사가 제작하거나 승인한 공식 프로그램이 아닙니다.

## 🛠️ 오류가 발생했나요?

먼저 다음 사항을 확인해 주세요.

1. LDPlayer 9에서 게임이 실행 중이며 내부 해상도가 **1280×720**인지 확인
2. ZIP을 전체 압축 해제했고 `_internal` 폴더가 유지되어 있는지 확인
3. ADB 연결 및 `adb.exe` 경로가 올바르게 설정되어 있는지 확인
4. 같은 숙제를 무작정 반복하지 말고 **게임 내 완료 횟수 및 재화 사용 상태**부터 확인
5. 프로그램의 **최근 원클릭 실행 결과 → 로그 폴더 열기**를 이용해 로그 확인

### 오류 제보 시 필요한 정보

- 문제가 발생한 숙제 단계
- 당시 게임 화면 스크린샷
- `UserData/logs/session.txt`
- `UserData/logs/oneclick_latest.json`
- 오류가 있다면 `UserData/logs/langmo_last_error.json`
- Windows 및 LDPlayer 버전
- 선택한 시공 스테이지와 관련 설정

### [💬 오류 및 개선 의견 남기기 (GitHub Issues)](https://github.com/parknana2222-ux/langmo-ld-helper/issues)

> 🔒 로그와 스크린샷에는 게임 닉네임, Windows 사용자 경로 등의 개인정보가 포함될 수 있습니다. 공개 게시글이나 Issues에 첨부하기 전에 반드시 확인하고 가려 주세요.
